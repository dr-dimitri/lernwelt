# Lernwelt 0.6.15

- Die Veröffentlichung wählt ihre Plattformartefakte jetzt namentlich aus. Zusätzliche Debugpakete aus dem aufrufenden Qualitätslauf gelangen nicht in die Release-Eingaben.
- Stabile Main-Releases behalten Apple Silicon und Windows x64 mit genau sechs Dateien und einem vollständigen Manifest. Fehlende Plattformpakete verhindern weiterhin die Veröffentlichung.
- Vorabversionen bleiben auf Apple Silicon begrenzt. Windows-Builds laufen ausschließlich für `main`; Pull Requests und RCs erzeugen keinen Windowsjob.

Die stabile Version übernimmt den geprüften Stand von **0.6.15-rc.1**: direkte Themenauswahl (#149), einklappbare Navigation (#151), aufeinander aufbauende Lernabzeichen (#152), vollständig versiegelte macOS-Bundles (#155), Apple-Silicon- und Windows-Pakete ohne neue Intel-Mac-Builds (#157), Windows-CI auf `main` (#159) und den getrennten Veröffentlichungsfix (#161). Die neue Version wird nach dem Merge automatisch gebaut und veröffentlicht. Bestehende Tags und Veröffentlichungen bleiben erhalten. Profile und Lernfortschritt bleiben lokal erhalten.

Die macOS-App hat eine vollständige Ad-hoc-Signatur, aber keine Apple-Notarisierung. Beim ersten Start kann eine individuelle Freigabe unter **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen** erforderlich sein.
