# Lernwelt 0.6.7

- Die linke Seitenleiste lässt sich über **Einklappen** auf eine schmale Symbolleiste reduzieren. Der Pfeil klappt sie wieder aus.
- Alle fünf Navigationsziele bleiben erreichbar. Ihre Namen erscheinen beim Darüberfahren und bleiben für Bildschirmleser verfügbar; die aktuelle Auswahl bleibt markiert.
- Die aktuelle Aufgabe erhält mehr Platz. Umschalten setzt Eingaben nicht zurück; die Seitenleiste bleibt bei Bereichswechseln eingeklappt. Nach einem Neustart ist sie wieder ausgeklappt.
- In schmalen Fenstern bleibt das beschriftete Menü verfügbar.

## Installieren und aktualisieren

Die Veröffentlichung enthält Pakete für macOS Apple Silicon, macOS Intel und Windows x64. In einer bereits installierten Version mit Updater lässt sich die neue Version über **App aktualisieren** installieren. Lernprofile und Fortschritt bleiben erhalten.
