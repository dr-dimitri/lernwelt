# Lernwelt 0.6.2

Pluto ergänzt die Sonnensystem-Reise als Zwergplanet mit Steckbrief, Umlaufbewegung und drei wechselbaren, vergrößerbaren NASA-Bildern. Die acht Planetenrätsel bleiben erhalten; die Bewegung folgt den realen Umlaufzeitverhältnissen bei 5–15 Sekunden pro Erdenjahr.

## Änderungen

- Nach jedem Merge baut und veröffentlicht GitHub CI automatisch ein neues Release mit einer höheren App-Version. Die Pipeline prüft Versionen und Releasehinweise und veröffentlicht erst nach vollständigen Builds aller drei Plattformen.
- GitHub entfernt gemergte Issue-Branches automatisch. Das LLM bereinigt die erledigten lokalen Branches nach Abgleich mit dem gemergten Pull Request.
- Bestehende Lernstände und Punkte bleiben erhalten. Keine neue Datenbankmigration oder Abhängigkeit.

## Installation und Update

- Mac mit Apple-Prozessor: `Lernwelt_0.6.2_darwin-aarch64.dmg`
- Mac mit Intel-Prozessor: `Lernwelt_0.6.2_darwin-x86_64.dmg`
- Windows 64 Bit: `Lernwelt_0.6.2_windows-x86_64-setup.exe`

In einer vorhandenen Lernwelt-App **App aktualisieren** wählen; die Installation beginnt erst nach Bestätigung. Alle Bilder und Lerninhalte bleiben offline verfügbar. Installer und Updater-Pakete erhalten Updater-Signaturen, aber keine Apple-Notarisierung oder Windows-Herausgebersignatur. Betriebssystemhinweise sind daher weiterhin möglich.
