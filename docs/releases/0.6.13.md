# Lernwelt 0.6.13

- **Zwei Release-Plattformen:** Die CI baut künftig macOS Apple Silicon und Windows x64. Der Intel-Mac-Build entfällt.
- Das Update-Manifest und die Veröffentlichung verlangen die beiden Pakete samt Signaturen sowie das Apple-Silicon-DMG: insgesamt sechs Dateien einschließlich `latest.json`. Fehlende oder zusätzliche Plattformartefakte verhindern eine Veröffentlichung.
- Die vollständige macOS-Bundle-Signaturprüfung vor dem Upload bleibt erhalten. Die Vorabversion enthält weiterhin die direkte Themenauswahl, die einklappbare Navigation, die Lernabzeichen und den macOS-Paketfix aus den vorherigen Vorabtests.

Dieser Test erscheint ausschließlich als **0.6.13-rc.1**. Kein Merge nach `main`; die stabile Version 0.6.8 und ihr Updatekanal bleiben unverändert. Bisher veröffentlichte Intel-Mac-Installer werden nicht entfernt oder verändert. Neue Versionen werden für Intel-Macs nicht mehr gebaut.

Die macOS-App erhält eine vollständige Ad-hoc-Signatur, aber keine Apple-Notarisierung. Beim ersten Start kann eine individuelle Freigabe unter **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen** erforderlich sein. Profile und Lernfortschritt bleiben lokal erhalten.
