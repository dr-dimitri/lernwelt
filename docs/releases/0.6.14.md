# Lernwelt 0.6.14

- **Windows-Builds nur auf main:** Pull Requests und Vorabversionen von Issue-Branches erstellen keine Windows-Jobs oder Windows-Pakete mehr. Apple Silicon bleibt dort prüf- und installierbar. Ein PR mit Ziel `main` zählt weiterhin als Nebenbranch-Prüfung.
- Stabile Main-Releases behalten Apple Silicon und Windows x64. Stabile Versionstags müssen wie bisher einen Commit auf `main` nachweisen; der Tagname allein schaltet Windows nicht frei.
- Neue Vorabversionen enthalten genau vier Dateien mit einem Apple-Silicon-Updateziel. Stabile Releases verlangen weiterhin sechs Dateien und beide Plattformen. Fehlende oder unerwartete Pakete verhindern die Veröffentlichung; die vollständige macOS-Bundleprüfung bleibt erhalten.
- Bestehende Windows-Vorabpakete und ältere Intel-Installer werden nicht verändert. Windows nutzt weiterhin den stabilen Updatekanal. Bei ausdrücklich aktivierten Vorabversionen kann die vorhandene Update-Prüfung auf Windows wegen eines fehlenden Windows-Pakets scheitern; ein Apple-Silicon-Paket wird nicht als Ersatz installiert.

Dieser Test erscheint ausschließlich als **0.6.14-rc.1** für Apple Silicon. Kein Merge nach `main`; die stabile Version 0.6.8 bleibt unverändert. Die direkte Themenauswahl, einklappbare Navigation, Lernabzeichen und der macOS-Paketfix der bisherigen Vorabversionen sind enthalten. Profile und Lernfortschritt bleiben lokal erhalten.

Die macOS-App erhält eine vollständige Ad-hoc-Signatur, aber keine Apple-Notarisierung. Beim ersten Start kann eine individuelle Freigabe unter **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen** erforderlich sein.
