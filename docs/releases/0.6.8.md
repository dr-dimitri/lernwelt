# Lernwelt 0.6.8

- Im Updatefenster können jetzt zusätzlich GitHub-Vorabversionen (Pre-Releases) angeboten werden. Die Option ist standardmäßig ausgeschaltet und wird auf dem Gerät gespeichert.
- Vorabversionen sind klar beschriftet. Beim Umschalten wird erneut geprüft; ältere Versionen, Entwürfe und Veröffentlichungen ohne Updater-Manifest werden nicht angeboten.
- Updates werden weiterhin erst nach einem Klick heruntergeladen und mit ihrer Signatur geprüft. Die automatische Startprüfung bleibt unabhängig einstellbar; Lernen bleibt offline möglich.
